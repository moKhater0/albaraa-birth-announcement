# بشارة ميلاد البراء

موقع عربي RTL متكامل لبشارة ميلاد الطفل **البراء**. التجربة مصممة كحكاية مرسومة تتحرك من سماء الصباح إلى المساء الهادئ، وتضم كشف صورة تفاعلي، بطاقة ميلاد، رسائل محلية، مشاركة، وكارت قابل للتحميل.

## التشغيل

يتطلب Node.js حديثًا وnpm.

```bash
npm install
npm run dev
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

للتحقق من المشروع:

```bash
npm run lint
npm run build
```

## تعديل معلومات المولود والنصوص

كل النصوص القابلة للتعديل موجودة مركزيًا في:

```text
data/birth.ts
```

يمكن من هناك تعديل الاسم، التاريخ، العناوين، الدعاء، الرسائل التجريبية، ونص المشاركة. حقلا الوزن والطول موجودان في النموذج كقيم فارغة ويمكن تفعيلهما مستقبلًا دون إعادة تصميم البيانات.

## إضافة صورة البراء الحقيقية

استبدل الملف:

```text
public/albaraa/images/baby-photo.webp
```

مع الاحتفاظ بنفس الاسم. لا يلزم تعديل الكود. يفضّل استخدام صورة عمودية بنسبة 4:5 تقريبًا. النسخة الحالية تحتوي على صورة بديلة جاهزة توضح أن الصورة ستضاف بعد الولادة.

## تعديل الألوان والمظهر

متغيرات الألوان وكل التنسيقات العامة موجودة في:

```text
app/globals.css
```

ألوان الهوية معرفة في بداية الملف كمتغيرات CSS، ويمكن تغييرها من مكان واحد.

## الرسومات والزخارف

الرسومات الحالية مصنوعة محليًا باستخدام SVG وCSS ولا تعتمد على روابط خارجية. لإضافة أو استبدال أصول زخرفية استخدم:

```text
public/albaraa/illustrations/
```

## المكوّنات الرئيسية

- `HeroBirthReveal.tsx`: مشهد السماء الافتتاحي وكشف اسم البراء.
- `WelcomeSection.tsx`: رسالة الترحيب ورسمة المهد.
- `BabyReveal.tsx`: تفاعل فتح السحب وكشف الصورة.
- `BirthCard.tsx`: الاسم والتاريخ في عناصر مرحة عائمة.
- `ParentsMessage.tsx`: الرسالة الهادئة من ماما وبابا.
- `BabyWishes.tsx`: الأمنيات التجريبية وإضافة أمنيات محلية محفوظة في المتصفح.
- `PrayerSection.tsx`: الانتقال المسائي والدعاء سطرًا بسطر.
- `FinalCelebration.tsx`: الخاتمة وأزرار المشاركة وتحميل كارت 1080×1920 بصيغة SVG.
- `components/decorative/`: السحب والطيور والنجوم والقمر والبالونات والزخارف المتحركة.

## الموسيقى الاختيارية

ضع ملفًا باسم:

```text
public/albaraa/audio/optional-background-music.mp3
```

إذا كان الملف موجودًا سيظهر زر التشغيل، ولن يعمل الصوت تلقائيًا. إذا لم يوجد الملف يظل الزر مخفيًا بلا أخطاء ظاهرة للمستخدم.

## ملاحظات

- المشاركة تستخدم Web Share API عند توفرها، وإلا ينسخ الموقع الرابط.
- الأمنيات الجديدة تبقى داخل المتصفح باستخدام `localStorage` ولا يوجد خادم أو قاعدة بيانات.
- الحركة تحترم إعداد `prefers-reduced-motion`.
- لا توجد أصول خارجية أو صور مخزنة عن بُعد في النسخة الحالية.

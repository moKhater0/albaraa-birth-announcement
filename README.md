# بشارة ميلاد البراء

موقع عربي RTL متكامل لبشارة ميلاد الطفل **البراء**. التجربة مصممة كحكاية مرسومة تتحرك من سماء الصباح إلى المساء الهادئ، وتضم كشف صورة تفاعلي، بطاقة ميلاد، سجل تهاني مشترك عبر Supabase، مشاركة، وكروت PNG للسوشيال.

## التشغيل

يتطلب Node.js حديثًا وnpm.

```bash
npm install
npm run dev
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

للتحقق من المشروع:

```bash
npm run lint
npm run build
```

## تعديل معلومات المولود والنصوص

كل النصوص القابلة للتعديل موجودة مركزيًا في:

```text
data/birth.ts
```

يمكن من هناك تعديل الاسم، التاريخ، العناوين، الدعاء، نصوص الحالات، ونص المشاركة. حقلا الوزن والطول موجودان في النموذج كقيم فارغة ويمكن تفعيلهما مستقبلًا دون إعادة تصميم البيانات.

## إضافة صورة البراء الحقيقية

استبدل الملف:

```text
public/albaraa/images/baby-photo.webp
```

مع الاحتفاظ بنفس الاسم. لا يلزم تعديل الكود. يفضّل استخدام صورة عمودية بنسبة 4:5 تقريبًا. النسخة الحالية تحتوي على صورة استرشادية مرسومة لتوضيح النتيجة قبل إضافة الصورة الحقيقية، وتظهر تلقائيًا في الموقع وفي كارت التحميل.

## إعداد قاعدة بيانات التهاني

1. أنشئ مشروعًا جديدًا في [Supabase](https://supabase.com/).
2. افتح **SQL Editor** داخل لوحة المشروع.
3. انسخ وشغّل محتوى الملف كاملًا:

```text
supabase/migrations/001_create_wishes.sql
```

الملف ينشئ جدول `public.wishes` والقيود والفهرس، ويفعّل RLS وRealtime. الزائر المجهول يستطيع قراءة الرسائل المعتمدة وإضافة رسالة صحيحة فقط، ولا يستطيع التعديل أو الحذف.

4. من شاشة **Connect** أو **Project Settings → API Keys** انسخ:

- Project URL
- Publishable key، ويبدأ عادةً بـ `sb_publishable_`

5. أنشئ ملفًا محليًا باسم `.env.local` وأضف:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your_key
```

لا تستخدم `service_role` أو أي secret key داخل متغير يبدأ بـ `NEXT_PUBLIC_`.

6. أعد تشغيل `npm run dev` بعد إضافة المتغيرات.

7. في Vercel افتح **Project Settings → Environment Variables** وأضف المتغيرين نفسيهما لكل البيئات المطلوبة:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

ثم أعد النشر.

### التأكد من عمل Realtime

افتح الموقع في نافذتين أو هاتفين، وأرسل كلمة من النافذة الأولى. يجب أن تظهر في الثانية دون تحديث الصفحة. إذا لم تظهر، تأكد أن ملف الترحيل نُفذ كاملًا وأن جدول `public.wishes` موجود داخل publication المسماة `supabase_realtime` من إعدادات Database Publications.

## تعديل الألوان والمظهر

متغيرات الألوان وكل التنسيقات العامة موجودة في:

```text
app/globals.css
```

ألوان الهوية معرفة في بداية الملف كمتغيرات CSS، ويمكن تغييرها من مكان واحد.

## الرسومات والزخارف

الرسومات الحالية مصنوعة محليًا باستخدام SVG وCSS ولا تعتمد على روابط خارجية. لإضافة أو استبدال أصول زخرفية استخدم:

```text
public/albaraa/illustrations/
```

## المكوّنات الرئيسية

- `HeroBirthReveal.tsx`: مشهد السماء الافتتاحي وكشف اسم البراء.
- `WelcomeSection.tsx`: رسالة الترحيب ورسمة المهد.
- `BabyReveal.tsx`: تفاعل فتح السحب وكشف الصورة.
- `BirthCard.tsx`: الاسم والتاريخ في عناصر مرحة عائمة.
- `ParentsMessage.tsx`: الرسالة الهادئة من ماما وبابا.
- `BabyWishes.tsx`: تحميل وإرسال التهاني المشتركة وحالات الانتظار والخطأ والفراغ.
- `PrayerSection.tsx`: الانتقال المسائي والدعاء سطرًا بسطر.
- `FinalCelebration.tsx`: الخاتمة والمشاركة وفتح مصمم كروت التحميل.
- `download-card/BirthDownloadCard.tsx`: تصميم مستقل للكارت بمقاسي Story وPost.
- `download-card/DownloadCardSheet.tsx`: اختيار المقاس والمعاينة وتصدير PNG بالحجم الأصلي.
- `lib/supabase/`: عميل Supabase وعمليات التهاني واشتراك Realtime.
- `components/decorative/`: السحب والطيور والنجوم والقمر والبالونات والزخارف المتحركة.

## الموسيقى الاختيارية

ضع ملفًا باسم:

```text
public/albaraa/audio/optional-background-music.mp3
```

إذا كان الملف موجودًا سيظهر زر التشغيل، ولن يعمل الصوت تلقائيًا. إذا لم يوجد الملف يظل الزر مخفيًا بلا أخطاء ظاهرة للمستخدم.

## ملاحظات

- المشاركة تستخدم Web Share API عند توفرها، وإلا ينسخ الموقع الرابط.
- التهاني تحفظ في Supabase وتظهر للمستخدمين الآخرين عبر Realtime. يستخدم `localStorage` فقط لمؤقت منع الإرسال المتكرر لمدة عشر ثوانٍ.
- كارت التحميل يُرسم كتركيب مستقل بدقة 1080×1920 أو 1080×1350 ثم يُصدّر PNG بعد انتظار تحميل الخطوط والصورة.
- الحركة تحترم إعداد `prefers-reduced-motion`.
- الصورة الاسترشادية الحالية مولدة خصيصًا للمشروع وليست صورة طفل حقيقي.
